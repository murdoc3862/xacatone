| 2026-11-05 | Python 3 + aiogram 3 | Популярно, много примеров на русском | Принято |

| 2026-11-05 | Бот и веб-панель в одном процессе (aiohttp из aiogram) | Один запуск, без лишних зависимостей; панель видит состояние бота напрямую | Принято |
| 2026-11-05 | Шаг регистрации определяется по базе (name пустой), без FSM в памяти | Переживает перезапуск бота | Принято |
| 2026-11-05 | Панель защищена Basic Auth, по умолчанию доступна только с этого компьютера (127.0.0.1) | Безопасно до деплоя; для доступа из интернета нужен HTTPS | Принято |
| 2026-11-05 | Long polling вместо webhook | Работает локально без домена | Заменено на сервере: webhook |
| 2026-11-05 | Хостинг: VPS Timeweb + свой домен, nginx + Let's Encrypt | Бот 24/7, база на диске сервера, панель по HTTPS | Принято, ждём доступы |
| 2026-11-05 | Код в GitHub (публичный репозиторий); `.env` и база в git не попадают | Секреты и персональные данные пользователей не должны быть публичными | Принято |
| 2026-11-05 | Выкладка на сервер через git (сервер тянет из GitHub по HTTPS) | История версий, легко откатиться, ключ на сервере не нужен (репозиторий публичный) | Принято |
| 2026-11-05 | Временно панель по http://IP без HTTPS | Домена пока нет; нужен доступ сейчас | Заменено: домен + HTTPS |
| 2026-11-05 | Домен xacatone.concie.ru + Let's Encrypt | Шифрование пароля панели, обязательное условие webhook | Принято |
| 2026-11-05 | Webhook на сервере, polling локально (переключается DOMAIN в .env) | Telegram сам доставляет сообщения, бот не держит постоянный опрос; локально домена нет | Принято |
| 2026-11-05 | Одновременно идёт только один тест | Проще участникам и рейтингу; запуск второго блокируется до остановки | Принято |
| 2026-11-05 | Место: больше верных → больше отвеченных → меньше времени от запуска | Уникальные места без ничьих, поощряет скорость | Принято |
| 2026-11-05 | Каждый запуск — отдельный «run» со своими результатами | Один и тот же тест можно запускать много раз, история не смешивается | Принято |
| 2026-11-05 | Тесты хранятся в коде (`bot/quizzes.py`), результаты — в базе | Вопросы версионируются в git; редактор вопросов в панели — позже при необходимости | Принято |
| 2026-11-05 | Зарегистрированным бот не отвечает автоматически, все сообщения идут в «Сообщения» | Разговор ведёт человек; автоответ мешал бы переписке | Принято |
| 2026-11-05 | Обновление переписки опросом раз в 4 с (fetch), а не WebSocket | Проще и надёжнее за nginx; для одного админа нагрузка ничтожна | Принято |
| 2026-11-05 | Медиа не храним у себя — показываем по file_id через Telegram | Не тратим диск сервера; Telegram хранит файлы сам | Принято |
