# Аналитика

## Что уже собирается
Таблица `events` в `data/bot.db`: каждое событие с временем и Telegram ID.
- `start` — нажал /start
- `registered` — ввёл имя
- `error` — ошибка бота (с текстом)

- `quiz_start` / `quiz_stop` — запуск и остановка теста

Тесты: `quiz_runs` (запуски), `quiz_participants` (участник в запуске: баллы, сколько отвечено, время, место), `quiz_answers` (каждый ответ).

## Метрики в панели
| Метрика | Где | Как считается |
|---|---|---|
| Зарегистрировано всего | /admin | users с заполненным именем |
| Зарегистрировано сегодня | /admin | registered_at = сегодня |
| Нажали /start | /admin | все строки users |
| Конверсия start → имя | /admin | зарегистрировано / нажали /start |
| Ошибок за 24 ч | /status | events type=error |
| Аптайм | /status | время с последнего запуска |
| Получили тест / начали / ответили на все / не доставлено | /quizzes | по текущему запуску |
| Средний балл запуска | /quizzes | AVG(score) среди ответивших |
| Рейтинг, ✅/❌ по вопросам, время | /quizzes/run/N | по запуску |
| % верных по каждому вопросу | /quizzes/run/N | помогает найти слишком сложные вопросы |
| Баллы пользователя за все тесты | /admin | сумма баллов / отвеченных вопросов |
