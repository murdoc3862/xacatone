# Журнал изменений

## 2026-11-05 — Тесты по истории России
- `bot/quizzes.py`: 10 тестов × 5 вопросов (от Древней Руси до распада СССР), 4 варианта, пояснение к каждому ответу
- Запуск теста из панели → рассылка всем зарегистрированным (≈20 сообщ./с, повтор при лимите Telegram, учёт недоставленных)
- В Telegram: вопрос с кнопками → после ответа сообщение заменяется разбором (✅ верный, ❌ выбранный неверный, пояснение) → следующий вопрос → итог «N из 5»
- Остановка теста из панели → каждому участнику место в рейтинге, его результат и топ-3; ответы после остановки не принимаются
- Регистрация во время идущего теста — новый участник сразу получает тест
- Панель: раздел «Тесты» (10 тестов с вопросами и ответами, кнопки Запустить/Остановить, ход теста, история запусков), страница результатов запуска (рейтинг, ✅/❌ по каждому вопросу, время, % верных по вопросам), колонка «Тесты» на странице пользователей
- База: таблицы `quiz_runs`, `quiz_participants`, `quiz_answers`; ответ засчитывается атомарно (двойное нажатие / перескок вопроса не проходят)
- Защита кнопок панели от CSRF (POST только со страниц самой панели)
- Проверено тестом: 3 участника, верные/неверные ответы, повторный ответ, остановка, рассылка мест, страницы панели

## 2026-11-05 — Домен xacatone.concie.ru, SSL, webhook
- DNS: A-запись `xacatone.concie.ru` (зона в NetAngels) → сервер Timeweb
- nginx настроен на домен, выпущен сертификат Let's Encrypt (до 03.02.2027), автопродление `certbot.timer`, http → https (301)
- Бот переведён на webhook: Telegram шлёт апдейты на `https://xacatone.concie.ru/tg/webhook`, запросы проверяются секретом `WEBHOOK_SECRET`
- Новые настройки `.env`: `DOMAIN`, `WEBHOOK_SECRET`; без `DOMAIN` бот работает по-старому (polling) — для локального запуска
- Панель состояния: проверка «Бот получает сообщения» в режиме webhook сверяет адрес в Telegram и последние ошибки доставки
- Тесты: webhook с верным секретом — 200 и регистрация, с чужим — 401; панели — без изменений
