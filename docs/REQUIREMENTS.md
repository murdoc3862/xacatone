# Требования к боту

## Назначение
Бот вебинара «Крутой Вебинар». Первая задача — регистрация пользователей.

## Функции
| # | Функция | Приоритет | Статус |
|---|---|---|---|
| 1 | /start → спросить имя → сохранить | Обязательно | Готово |
| 2 | Админ-панель: список всех зарегистрированных | Обязательно | Готово |
| 3 | Панель проверки, что бот работает | Обязательно | Готово |
| 4 | Выгрузка пользователей в CSV | Желательно | Готово |
| 5 | Доступ к панели из интернета | Обязательно | Готово (https://xacatone.concie.ru) |
| 6 | 10 тестов по истории России по 5 вопросов | Обязательно | Готово |
| 7 | Запуск / остановка теста из панели | Обязательно | Готово |
| 8 | Разбор каждого ответа и итог в Telegram | Обязательно | Готово |
| 9 | Рассылка мест в рейтинге при остановке | Обязательно | Готово |
| 10 | Результаты тестов в панели | Обязательно | Готово |
| 11 | Переписка с подписчиками из панели | Обязательно | Готово |

## Сценарий регистрации
1. Новый пользователь → /start → «Привет! Как вас зовут?»
2. Ввёл имя (2–50 символов) → «Приятно познакомиться, {имя}! Вы зарегистрированы.»
3. Ввёл некорректно → просьба повторить
4. Повторный /start → «С возвращением, {имя}!»
5. Прислал не текст (стикер, фото) → просьба написать текстом

## Что сохраняем о пользователе
Имя (введённое), Telegram ID, username, имя/фамилия из профиля Telegram, время первого /start, время регистрации.

## Сценарий теста
1. Админ в панели → «Тесты» → «Запустить» у нужного теста
2. Всем зарегистрированным приходит приглашение и вопрос 1 с кнопками А–Г
3. Участник жмёт ответ → сообщение превращается в разбор (✅/❌ + пояснение) → приходит следующий вопрос
4. После 5-го вопроса: «Ваш результат: N из 5. Место пришлю после остановки»
5. Админ → «Остановить тест» → каждому участнику: место, результат, топ-3; не ответившим — приглашение на следующий тест
6. Повторяется при каждом запуске любого теста; результаты каждого запуска сохраняются отдельно
